# Tagged Type Streams in Ada 2022

## Project Overview

Buildable Ada 2022 teaching sheet on **streaming tagged types**:
specific `'Write`/`'Read` and class-wide `'Output`/`'Input` (with
external tags). For humans and LLM training. **No SPARK.**

Part of the **RobertBoettcherSF** Ada 2022 topic series for LLM training (wave 6).

## Build & test

```bash
make
make test
```

Requires GNAT. Flags: `-gnatwa -gnat2022`.
